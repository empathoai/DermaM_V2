# AGENTS.md

This repo's rules for coding agents live in [CLAUDE.md](CLAUDE.md) — read that file first, whichever agent or tool you are. This file exists only because some tools look for `AGENTS.md` by convention. There is no separate rule set here — it is not a fallback source of truth.
